# Eva 智能座舱 · 功能说明手册

> 给团队的功能速查手册：每个功能**是什么、怎么触发、背后做了什么**。
> 路演 Q&A 前建议全员通读一遍；所有阈值数字集中在文末参数速查表。

- 启动：`npm run dev` → http://localhost:5173
- 一句话定位：**机器视觉守护的 L2 辅助驾驶座舱智能体**——浏览器本地人脸识别监测驾驶员疲劳/分神，与行车工况双通道融合，让 Eva 智能体"看得见驾驶员"地主动干预。
- 安全边界：全项目定位 **L2 辅助驾驶**（自适应巡航 + 车道居中），驾驶员始终是责任主体；Eva 的所有动作只到"提醒、建议、座舱调节、辅助降级"为止。
- 展示语言：所有用户可见界面与播报为英文；本手册继续使用中文供团队内部协作。

## 二、核心功能详解

### F1 机器视觉 DMS（驾驶员监测）——项目最大亮点

**是什么**：打开摄像头后，在浏览器本地识别人脸 **478 个关键点**，实时算出驾驶员的疲劳与分神指标。画面全程本机推理，**不上传任何影像**。

**怎么触发**：打开 `Evidence`，在 Perception 列点 `Live DMS` 请求浏览器摄像头，或点 `Simulation` 使用模拟信号；可同屏查看画面、关键点与完整指标。没有摄像头时仍走**同一套指标算法**，演示不中断。

**背后做了什么**（三层）：

1. **模型推理**：MediaPipe FaceLandmarker（自托管于 `public/models/`，3.7MB，Apache-2.0），WASM/GPU 本地运行；模型加载三源容灾（本地 → Google CDN），GPU 失败自动降 CPU。
2. **指标解算**（`src/vision/metrics.ts`，纯函数、可单测）：
   - **EAR 眼睛纵横比**：每眼 6 个关键点，`(上下眼睑距离之和) / (2×眼宽)`；EAR < 0.15 判定为闭眼帧；
   - **PERCLOS**：30 秒滑动窗口内闭眼帧占比（学术界公认的疲劳金标准指标）；
   - **眨眼频率**：闭眼事件计数折算每分钟次数；
   - **头部姿态**：从模型输出的 4×4 变换矩阵解出 yaw/pitch 欧拉角，偏航 >22° 或俯仰 >18° 记为"视线离开"，持续累计秒数。
3. **融合决策**：视觉指标折算成"视觉疲劳度"（PERCLOS × 185；视线离开每秒 +6、封顶 40），与工况仿真疲劳度**取强融合**（谁大听谁的）→ 得到综合疲劳度 0–100。

### F2 疲劳守护（双阈值分级干预）

**是什么**：综合疲劳度越过阈值时，Eva 分两级干预，而不是一味唠叨。

| 级别 | 触发 | Eva 的动作 |
|---|---|---|
| 温柔关怀 | 疲劳度 ≥ **60** | 加强通风一档、调低温度 1.5℃、切轻音乐，语言关怀提醒休息（8 仿真分钟冷却） |
| 紧急干预 | 疲劳度 ≥ **85** | 紧急告警 + 弹出**用户选择分支**：「立即休息 / 再坚持一会儿」（15 仿真分钟冷却） |

**休息分支逻辑**：选「立即休息」→ 进入休息模式（关音乐、开按摩、氛围灯调暖、23.5℃），疲劳恢复到低位自动退出；选「再坚持」→ **6 仿真分钟后若仍是重度疲劳会再次升级提醒**（尊重用户但不放弃守护）。

**怎么演示**：底部 `SCENE` 选择 `Fatigue Guard`，系统会复位后开始对应仿真；阈值、选择分支与恢复逻辑仍由同一内核执行。

### F3 分神守护 + L2 降级/恢复

**是什么**：驾驶员视线持续离开路面时，系统不只是提醒，还会**动真格降级辅助驾驶**。

| 视线离开时长 | 系统动作 |
|---|---|
| ≥ 2 秒 | warn 告警"请注意路面"（1.5 仿真分钟冷却） |
| ≥ 4 秒 | **urgent 告警 + L2 立即降级**：目标车速 ×0.85、拉大跟车时距，Eva 语音催促回看路面 |
| 回正 < 0.5 秒 | 自动恢复正常 L2 策略，发 info 通知 |

另外：视觉开着但**画面里没有人**（驾驶员离开座位/趴下）→ 每 10 仿真分钟 warn 提醒确认坐姿。

### F4 Eva 拟人智能体

**是什么**：有五种工作模式的座舱智能体。主舞台同一时刻只显示一句 EVA 叙事；完整自然语言输入、待确认分支与执行证据放在 `Evidence → Execution`。

**模式（优先级从高到低）**：干预中（L2 已降级）→ 休息引导中 → 谨慎模式（复杂路况）→ 守护中（疲劳≥60）→ 观察中。

**情绪四联动**：情绪值 ≤32（低落）→ 暖色氛围灯 + 舒缓音乐 + 轻柔按摩；≥68（亢奋）→ 切舒缓曲 + 加强通风——都是"帮驾驶员回到平稳状态"。

### F5 自然语言指令（对话输入框直接打字）

| 你说 | Eva 做 |
|---|---|
| `I am sleepy / tired` | 疲劳设为 ≥63 + 通风提神组合（风量+1、降温、动感音乐）+ 主动建议服务区 |
| `hot` / `cold` | 降/升温 1.5℃（区间 18–30℃） |
| `music / song` | Soft → Upbeat → News 循环切换 |
| `mute / stop music` | 关闭音乐 |
| `massage` | 开关座椅按摩 |
| `navigation / how long / how far` | 报剩余公里数 + 预计分钟 |
| `rest / service area / stop` | 进入休息模式 |
| `L2 on / L2 off` | 开关 L2 辅助驾驶 |
| 其他 | 礼貌说明能力范围 |

### F6 复杂路况协同（舱驾联动）

**是什么**：雨、夜、拥堵三个因子**计数 ≥2** 时自动进入「谨慎模式」：屏蔽娱乐（音乐关闭并记住之前曲目）、强化安全播报、修正目标车速（雨 ×0.85、夜 ×0.92、弯道最多 ×0.94，连乘）。路况缓解后**自动恢复**娱乐与常规座舱服务。

### F7 整车数字孪生电影主舞台

主视图直接加载 Three.js 整车；道路、车道线、城市体块、光门和模拟前车全部锚定到车辆舞台坐标系，并按车型几何纵轴校准。通勤为正后追，疲劳切入半透明舱内 DMS，复杂路况为低位雨夜后追，恢复阶段再切高位广角。轮胎最低点与道路/静态展台统一留出安全间隙，不制作轮动特效。WebGL 或模型失败时保留 EVA 状态画面，故事、控制与证据仍可运行。

### F8 原三幕 60 秒巡演 + 三个独立场景

| 场景 | 剧情脚本 |
|---|---|
| 日常通勤 | 上车问候 + 人脸识别确认身份 → 按习惯调座舱（22.5℃/青碧氛围/轻音乐）→ 规划 12.6km 常用路线 |
| 疲劳守护 | 高速 96km、L2 开启、疲劳 62 关怀 → 88 紧急干预 → 驾驶员选择休息 |
| 复杂路况 | 脚本化依次注入：雨 → 拥堵 → 夜 → 前车急刹 → 触发谨慎模式与舱驾协同 |

**自动演示**：首页点 `Run Live Demo` 会在舞台就绪后自动开演；直接访问 `#/cockpit` 停在 `Start Experience`。约 60 秒依次走通勤、疲劳、复杂路况三幕，随时 `Pause / Continue / Replay Tour`；暂停与完成均冻结时间和路线。DMS 可使用本地摄像头或模拟信号，驾驶环境明确标注为仿真。

### F9 无障碍

证据抽屉内提供字号四档缩放（偏好持久化）、高对比、英文 TTS；支持完整键盘操作、跳转链、Escape 关闭抽屉、紧急告警 aria-live assertive 播报，以及 `prefers-reduced-motion` 静态切镜。

### F10 仿真系统（所有动态行为的底层）

- 车速：目标速度一阶惯性趋近（时间常数 0.9 仿真分钟）；拥堵工况叠加正弦"走走停停"；前车急刹目标 −22 km/h；
- 疲劳累积：基础 0.08/仿真分钟，拥堵 ×2.75，高速 >85km/h ×5.25，疲劳场景再 ×1.6；休息时以 2.6/分钟恢复；
- 播放状态与仿真时钟绑定：仅 `running` 推进；ready / paused / completed 保持当前路线与时间。

## 六、F11 电影化叙事层（EvaNarration + CinemaControls）

**是什么**：顶栏给出当前镜头标题及无文字三段进度，底部只保留 EVA 一句话、播放控制与场景菜单；完整指标不与叙事争夺注意力。

**怎么触发**：`Start Experience`、首页自动接力或快捷键 `D`；Space 控制暂停/继续。

**九步讲解剧本**（与演示事件逐拍对齐）：

| 步 | 讲解要点 |
|---|---|
| 1 | City Commute：欢迎、偏好座舱与常用路线 |
| 2 | Fatigue Guard：高速 + L2 的端侧 DMS 监测 |
| 3 | 疲劳 62：橙色轻度关怀与座舱调节 |
| 4 | 疲劳 88：红色紧急干预与休息选择 |
| 5 | Rest now：驾驶员确认休息，青色恢复反馈 |
| 6 | Complex Roads：雨、夜、拥堵与前车制动 |
| 7 | Conditions ease：恢复常规服务 |
| 8 | Voice command：导航自然语言指令 |
| 9 | Demo complete：整车广角冻结，驾驶员责任不变 |

**背后**：剧本是纯数据（9 个稳定 cue、时间严格递增、每步有英文讲解）；单一调度器支持暂停/继续/重播；`aria-live="polite"` 提供读屏播报，减弱动态模式使用静态切镜。

## 七、F12 非阻塞入场遮罩 EntryTransition

**是什么**：驾驶舱和三维舞台从首帧就挂载，共享 EVA 头像遮罩约 1 秒自动淡出，1.2 秒有硬兜底；后方模型继续加载，异常时头像保留但系统可操作。

**怎么触发**：每次进入 `#/cockpit` 自动播放；遮罩不阻塞后方资源初始化。

**背后**：稳定回调 + 1.2 秒硬上限有单元测试保护；`prefers-reduced-motion` 下直接淡入。旧 `BootSplash` 仅保留兼容代码，不再是主演示入口。
