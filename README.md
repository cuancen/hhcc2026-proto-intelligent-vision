# EVA Vision Loop —— 看见原因、闭环解决的 L2 辅助驾驶舱内智能体

> 吉利黑客松 · 原型开发赛道（Prototype Development Track，官方开发期内从零搭建）
> 创新主线：**机器视觉赛道 × 智能座舱** —— 让 EVA 从“检测驾驶员状态”升级为“理解车内正在发生什么”：将驾驶员 DMS、物品语义事件与行车工况关联，找到风险原因、采取行动并确认问题是否解决。

## 定位声明（重要）

本产品定位为 **L2 组合辅助驾驶**（驾驶员监测 + 自适应巡航 + 车道居中辅助）：
系统在车道内辅助转向与加减速，**驾驶员始终是驾驶责任的主体**，需保持对路况的监管并随时准备接管。
全项目（界面、话术、文档）不使用 L3/L4 自动驾驶表述；Eva 的所有干预均以"提醒、建议、座舱调节、辅助降级"为边界。

## 功能总览

| 模块 | 内容 |
|---|---|
| 机器视觉 DMS | 摄像头 → MediaPipe 面部关键点（478 点，浏览器本地 WASM/GPU 推理，零上传）→ EAR 眨眼 / PERCLOS 闭眼占比 / 头部姿态偏航俯仰 / 驾驶员在位 |
| EVA 情境记忆 | 将物品、位置、重要度与变化保存为语义事件；比赛原型的物品输入明确标记为模拟，不保存原始视频，不宣称通用物体识别 |
| 原因理解与闭环确认 | 将“持续向左下方看”与“寻找停车卡”关联，告知位置、打开阅读灯，再由 DMS 确认视线回正 |
| 双通道疲劳融合 | 工况累积疲劳（车速/路况/时长）与视觉 PERCLOS 取强融合，60 温柔关怀 / 85 紧急干预 + 休息选择分支 |
| 分神守护 | 视线离开 ≥2s 预警、≥4s 紧急告警并 L2 降级（缩速、拉大时距），回正自动恢复 |
| Eva 拟人智能体 | 表情/模式联动、对话流、情境快捷回复、自然语言指令（冷热/音乐/按摩/导航/休息/辅助开关） |
| 复杂路况协同 | 雨+夜+拥堵因子 ≥2 → 屏蔽娱乐、谨慎模式；缓解后自动恢复 |
| 态势主视图 | Canvas 伪三维道路（昼夜/雨/弯道/前车刹车灯）+ HUD（车速/L2 状态/降级提示） |
| 60 秒主演示 | 看见物品 → 发现寻找行为 → 理解分心原因 → 精准协助 → 视觉确认 → 离车重要物品提醒；原三场景仍可手动体验 |

## 快速开始

```bash
npm install     # postinstall 自动将 MediaPipe WASM 拷贝到 public/（自托管，离线可用）
npm run dev     # http://localhost:5173
npm test        # 48 项内核/视觉/shell 回归（vitest，零 DOM 内核）
npm run build   # 类型检查 + 生产构建
```

**演示建议**：进入页面后点 `▶ 自动演示`（约 60 秒走完 EVA Vision Loop 主闭环）；或按 `1/2/3/4` 切换日常通勤、疲劳守护、复杂路况与情境闭环，`D` 演示、`L` 切换 L2。
想体验真实机器视觉：点 DMS 面板的 `📷 开启摄像头监测`（画面全程本地推理，不上传）；无摄像头时用 `模拟信号`——它与真实模型走同一套指标管线。

## 技术架构

```
src/
├── core/      内核（零 DOM，可独立测试/迁移）
│   ├── sim.ts        仿真动力学：速度/疲劳/情绪/路况
│   ├── evaRules.ts   Eva 规则引擎：情境关联 + 冷却闸门 + 场景脚本队列 + 用户分支
│   ├── adas.ts→并入 sim/eva  L2 策略：降级/恢复/监管提醒
│   └── params.ts     参数唯一出处（阈值/速率/冷却）
├── vision/    机器视觉
│   ├── metrics.ts    纯函数：EAR/头姿解算/PERCLOS 窗口/视线离开追踪
│   ├── dms.ts        MediaPipe 引擎：多源容灾（本地 WASM→jsDelivr→unpkg；GPU→CPU）
│   └── simVision.ts  模拟信号回退（与真实管线共用 metrics）
└── shell/     UI 外壳（React 18 + TS）
    ├── hooks/  useCockpit（interval 驱动 100ms）/ useDms / useUiPrefs
    └── components/ 10+ 面板组件（含情境时间轨 ContextPanel）
```

稳定性设计：仿真由 `setInterval` 驱动（后台标签页不冻结）；视觉模型自托管于 `public/`（`face_landmarker.task`，Apache-2.0），WASM 运行时三源容灾；摄像头/模型任何失败都降级为模拟信号，演示永不中断。参数表与验证流程见 `docs/PIPELINE.md` 与 `AGENTS.md`。

## 声明

- 演示中的车速、疲劳速率、温度等为**仿真假设值**（集中定义于 `src/core/params.ts`），非量产标定；
- 物品位置、重要度与“寻找停车卡”意图为**透明标注的模拟视觉事件**；真实实现需要车内物体检测、跟踪、归属与遮挡恢复能力，本原型不作对应准确率声明；
- MediaPipe Face Landmarker 模型与运行时遵循 Apache-2.0，自托管分发；
- 摄像头画面仅在本设备浏览器内推理，不采集、不上传任何影像。
